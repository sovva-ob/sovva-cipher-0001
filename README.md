# cipher
a simple encryption and decryption application built as a python learning project.

### technologies
python · flask · javascript · html · css

### features
- caesar-style encryption and decryption
- customizable character shifts
- interactive terminal interface

### run
install flask with `pip install flask`, then run `python app.py`.
